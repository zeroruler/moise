# Moise

주소를 붙여넣고 버튼 한 번으로 mp4 영상이나 mp3 음원을 받는 가벼운 macOS 앱.

- 다운로드 페이지: https://zeroruler.github.io/moise/
- 최신 버전 받기: [Moise.dmg](https://github.com/zeroruler/moise/releases/latest/download/Moise.dmg)

macOS 13 이상 (Apple Silicon · Intel). Homebrew로 설치한 `yt-dlp`, `ffmpeg`가 필요해요.

```bash
brew install yt-dlp ffmpeg
```

개인용·비상업적 용도로 만든 앱이에요. 저작권 문제가 없는 콘텐츠에만 사용해 주세요.
